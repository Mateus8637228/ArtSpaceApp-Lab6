# Лабораторная №6 — задание 2: ArtSpaceApp

Исходное приложение из предыдущей лабораторной работы доработано без изменения
трёх картин, подписей и адаптивного оформления. `ArtSpaceUiState` и
`ArtSpaceViewModel` реализуют UDF; состояние отдаётся через неизменяемый StateFlow.
Выбранная картина сохраняется при пересоздании Activity из-за поворота экрана.

Открыть проект отдельно в Android Studio, выбрать JDK 25 и SDK 37.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

Тесты проверяют переходы, границы, отключённые кнопки и настоящий поворот экрана.
Исходные Example-тесты сохранены. Проверка перед публикацией: [SECURITY.md](SECURITY.md).
Изменения лабораторной изолированы от исходного состояния предыдущей работы.
